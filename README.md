# CSAI, a machine learning model created to predict Counter-Strike matches

A machine learning-based predictive model designed to estimate the outcome of a Counter-Strike round based on economic factors, weapon loadouts, and number advantages. The model helps users understand strategic elements of the game and supports data-driven decision-making.

### Getting Started

Running ML model:

Start within 1. Data, view each Jupyter notebook in numerical order, and follow instructions.

Running website:

1. clone repository using git clone
2. cd website_deployment
3. cd csai-app
4. pip install -r requirements.txt
5. cd src
6. python main.py
7. open website locally
